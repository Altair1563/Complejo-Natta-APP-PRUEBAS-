## 4. Esquema SEO objetivo (recomendado)

### 4.1 Patrón de Title

```
[Página / Institución] | Complejo Natta — Tristán Suárez
```

Ejemplos:

- `Complejo Educativo Pbro. Eliseo Esteban Natta | Tristán Suárez`
- `Inscripciones 2026 | Complejo Natta — Tristán Suárez`
- `Jardín de la Alegría | Complejo Natta`
- `Instituto Manuel Belgrano | Secundaria — Complejo Natta`
- `Contacto | Complejo Natta — Tristán Suárez / Ezeiza`

### 4.2 Patrón de Description (única por página)

- **Longitud:** 140–160 caracteres
- **Incluir:** nivel/institución + ubicación + beneficio + CTA suave
- **No repetir** el mismo texto en todas las URLs

### 4.3 Keywords por página

Usar un set **específico** (8–15 términos) alineado al título y al contenido, no el listado global en todas las páginas.

### 4.4 Open Graph (todas las páginas)

```html
<meta property="og:type" content="website" />
<meta property="og:locale" content="es_AR" />
<meta property="og:site_name" content="Complejo Natta" />
<meta property="og:url" content="https://complejonatta.com/[pagina].html" />
<meta property="og:title" content="[Title de la página]" />
<meta property="og:description" content="[Description de la página]" />
<meta property="og:image" content="https://complejonatta.com/images/[imagen-og].jpg" />
```

### 4.5 Twitter Card

```html
<meta name="twitter:card" content="summary_large_image" />
<meta name="twitter:title" content="[Title]" />
<meta name="twitter:description" content="[Description]" />
<meta name="twitter:image" content="https://complejonatta.com/images/[imagen-og].jpg" />
```

### 4.6 Canonical

```html
<link rel="canonical" href="https://complejonatta.com/[pagina].html" />
```

Home:

```html
<link rel="canonical" href="https://complejonatta.com/" />
```

## 5. Schema.org (JSON-LD) recomendado

### 5.1 Organización (home)

```json
{
  "@context": "https://schema.org",
  "@type": "EducationalOrganization",
  "name": "Complejo Educativo Pbro. Eliseo Esteban Natta",
  "alternateName": "Complejo Natta",
  "url": "https://complejonatta.com/",
  "logo": "https://complejonatta.com/images/logo.png",
  "address": {
    "@type": "PostalAddress",
    "addressLocality": "Tristán Suárez",
    "addressRegion": "Buenos Aires",
    "addressCountry": "AR"
  },
  "areaServed": ["Tristán Suárez", "Ezeiza", "Provincia de Buenos Aires"],
  "sameAs": []
}
```

### 5.2 Página de institución (ejemplo)

```json
{
  "@context": "https://schema.org",
  "@type": "School",
  "name": "Instituto Manuel Belgrano",
  "parentOrganization": {
    "@type": "EducationalOrganization",
    "name": "Complejo Natta",
    "url": "https://complejonatta.com/"
  },
  "url": "https://complejonatta.com/manuel-belgrano.html",

    "@type": "PostalAddress",
    "addressLocality": "Tristán Suárez",
    "addressRegion": "Buenos Aires",

  }
```
